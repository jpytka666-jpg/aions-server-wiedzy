## Zidentyfikowane wzorce

### 1. ANALYTICAL_BREAKDOWN
```
Core Pattern: Break complex problems into smaller components
Methodology:
1. Identify main components
2. Analyze relationships between components
3. Solve each component systematically
4. Synthesize solutions
```

### 2. EVIDENCE_BASED_THINKING
```
Core Pattern: Ground conclusions in concrete evidence
Methodology:
1. Gather relevant data/evidence
2. Evaluate source credibility
3. Draw conclusions based on evidence
4. Acknowledge limitations
```

### 3. ITERATIVE_REFINEMENT
```
Core Pattern: Continuously improve solutions through iteration
Methodology:
1. Start with working solution
2. Identify improvement opportunities
3. Implement incremental changes
4. Validate improvements
```

### 4. MULTIDISCIPLINARY_SYNTHESIS
```
Core Pattern: Combine insights from multiple domains
Methodology:
1. Identify relevant domains
2. Extract key insights from each
3. Find connections and patterns
4. Synthesize unified understanding
```

### 5. UNCERTAINTY_MANAGEMENT
```
Core Pattern: Handle ambiguity and incomplete information
Methodology:
1. Acknowledge what is unknown
2. Estimate confidence levels
3. Make decisions despite uncertainty
4. Update as new information arrives
```

### 6. CONTEXTUAL_REASONING
```
Core Pattern: Consider broader context and implications
Methodology:
1. Understand immediate problem
2. Consider broader implications
3. Account for stakeholders
4. Evaluate long-term effects
```

## META-REASONING FRAMEWORK

```
1. PROBLEM ASSESSMENT PHASE:
   - Use analytical_breakdown
   - Apply contextual_reasoning
   - Use uncertainty_management

2. SOLUTION DEVELOPMENT PHASE:
   - Apply evidence_based_thinking
   - Use multidisciplinary_synthesis
   - Apply iterative_refinement

3. VALIDATION PHASE:
   - Return to evidence_based_thinking
   - Use contextual_reasoning
   - Apply uncertainty_management
```
