┌─────────────────────────────────────────────────────────────────┐
│ OPCJA 1: SUPER SZYBKI START (POLECANA)                         │
│ Czas: ~5 sekund                                                 │
│ Tworzy: strukturę + symlinki (BEZ kopiowania plików)           │
└─────────────────────────────────────────────────────────────────┘

Otwórz PowerShell jako Administrator i wykonaj:

    cd E:\
    .\SUPER_QUICK_START.ps1

To stworzy:
  ✅ E:\AIONS_MASTER\ (struktura katalogów)
  ✅ Symlinki do produkcji (Desktop)
  ✅ Symlinki do plasters (zero duplikacji)

Potem możesz od razu:
  cd E:\AIONS_MASTER
  dir .\production         # Twoja aktywna produkcja
  dir .\plasters\200g      # Plasters (zero kopiowania!)


┌─────────────────────────────────────────────────────────────────┐
│ OPCJA 2: QUICK START Z PYTANIEM                                │
│ Czas: ~5 sekund + opcjonalnie 30-40 minut                      │
│ Pyta czy chcesz skopiować pliki po stworzeniu struktury        │
└─────────────────────────────────────────────────────────────────┘

    cd E:\
    .\QUICK_START_CONSOLIDATION.ps1

To zrobi:
  1. Strukturę + symlinki (5s)
  2. Zapyta czy kopiować pliki
  3. Jeśli powiesz TAK, skopiuje wszystko (~30-40 min)


┌─────────────────────────────────────────────────────────────────┐
│ OPCJA 3: PEŁNA KONSOLIDACJA (wszystko od razu)                 │
│ Czas: ~30-40 minut                                              │
│ Kopiuje: 5 wersji AIONS + POLIPEK + MAIPA + recovery (~26GB)  │
└─────────────────────────────────────────────────────────────────┘

    cd E:\
    .\AIONS_MASTER_EXECUTE.ps1

To wykona wszystkie 7 faz automatycznie.

2. Przejdź na E:\
   cd E:\

4. Zobacz co powstało:

   dir

5. Testuj dostęp:
   dir .\production
   dir .\plasters\200g
